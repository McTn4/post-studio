Lo que comparten los cinco

Están pensados como base de trabajo: puedes cambiar el color de marca en una sola línea (las variables CSS están al principio de cada archivo), sustituir los textos y publicar. No hay procesos de compilación ni dependencias que se rompan con el tiempo.

  • Un único archivo HTML autónomo por modelo
  • Sin GSAP ni frameworks: solo CSS y JavaScript nativo
  • Animación desactivada si el sistema lo pide
  • Diseño adaptado de 360 px a pantallas panorámicas
  • Contenido genérico, listo para cualquier sector
  • Foco visible y estructura semántica
