Características

Profundidad donde importa,
simpleza en todo lo demás.

Cada superficie tiene una función: separar, agrupar o destacar. Nada de cristal por decoración.

Sistema por capas

Fondo, superficie y contenido siempre en el mismo orden. El usuario nunca duda de dónde está mirando.

Luz que responde

El foco sigue al cursor y resalta solo el elemento activo. Una guía sutil, nunca un espectáculo.

Ligero

Sin librerías externas. Todo el movimiento es CSS y unas pocas líneas de código.

Adaptable

La profundidad se reduce en pantallas pequeñas para que nada estorbe la lectura.

Para todos

Contraste verificado y desactivación automática del movimiento cuando el sistema lo pide.
